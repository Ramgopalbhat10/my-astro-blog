Notes is my markdown vault. It loads a prebuilt file tree from S3, shows that tree right away, and fetches each note when I open it.

## Features

- Cached file tree backed by S3, with markdown loaded as you select a file
- Markdown preview, including Mermaid diagrams, and an installable progressive web app
- GitHub login, plus an optional API key so other apps can read and write notes
- AI chat and edit actions on a note
