Personal markdown vault that loads a prebuilt file tree from S3 and fetches each note as you open it.
- Cached file tree backed by S3, with markdown loaded as you select a file.
- Markdown preview with Mermaid diagrams, and an installable progressive web app.
- GitHub login, plus an optional API key so other apps can read and write notes.
- AI chat and edit actions on the note you have open.
