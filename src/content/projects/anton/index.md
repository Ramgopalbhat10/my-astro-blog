Personal coding agent in the browser. Pick a GitHub repo and branch, describe the outcome, and it works on its own branch in a sandbox.
- Side panel shows Changes, Terminal, Files, and Library while a task runs.
- Starts read-only, then opens a sandbox when the work needs edits, commands, or a pull request.
- Plan mode, so it can investigate and propose a plan before changing anything.
- Opens a pull request, then a second agent reviews the change on GitHub.
- Installs on a phone and can notify you when a task needs an answer or a plan approval.
